## 2. LETTERHEAD

### A4 Official Letterhead

**Header Zone (top 35mm):**
```
Left: ZARATI logo (compact, full color)
Right: Contact block (website, email, phone) — type-caption, right-aligned
Bottom of header: 2px rule, ZA-GREEN-400, full width
```

**Content Zone:**
- Top margin: 45mm (below header + 10mm clear space)
- Bottom margin: 30mm
- Side margins: 25mm each
- Font: Inter, `type-body-md`, `ZA-NEUTRAL-800`
- Paragraph spacing: 12pt between paragraphs

**Footer Zone (bottom 20mm):**
```
Left: "ZARATI | زرعتي" — ZA-NEUTRAL-500, type-caption
Center: Physical address
Right: Registration / legal number
Top of footer: 1px rule ZA-NEUTRAL-200
```

### Arabic Letterhead Variant
- Mirror layout: Logo right-aligned, content RTL
- Font: IBM Plex Arabic for all Arabic text
- Footer: Arabic address first, then English

## 5. GOVERNMENT REPORT TEMPLATE

### Design Principles for Government
- **Conservative and formal** — no gradients, no hero imagery on content pages
- **Bilingual mandatory** — every page has both Arabic and English
- **Print-ready** — CMYK color values, proper bleed/margin setup
- **Compliance-ready** — space for official stamps, reference numbers, classification marks

### Report Structure
```
1. OFFICIAL COVER
   - Sudan government crest positioning (top-left)
   - ZARATI logo (top-right, balanced)
   - Report title: Arabic (primary, type-h1) + English (secondary, type-h2)
   - Ministry name, date, reference
   - Confidentiality classification band

2. HEADER (every page)
   - Report title (short) — left
   - Page number and reference — right
   - 1px separator rule, ZA-NEUTRAL-200

3. SECTION HEADERS
   - All uppercase, type-h3, ZA-NAVY-900
   - Left accent bar 4px ZA-GREEN-400

4. DATA TABLES
   - Formal grid, no rounded corners
   - Header row: ZA-NEUTRAL-800 bg, white text
   - Alternating rows: white + ZA-NEUTRAL-50

5. CHARTS
   - Single-color preference for formal reports
   - Always include data table below/alongside chart
   - Arabic axis labels + English below

6. OFFICIAL FOOTER
   - Left: ZARATI name + contact
   - Right: Report reference + classification
   - Center: Page X of Y
```
