## 3. SOCIAL POST TEMPLATES

### Template 1: Data Insight Post
**Used for:** Statistics, research findings, impact numbers
```
Background: ZA-NAVY-900 full bleed
Top-left: ZARATI logo (compact white version)
Center: Large number (type-display-xl, white)
Below number: Short descriptor (type-body-lg, ZA-GREEN-400)
Bottom: Source line (type-caption, ZA-NEUTRAL-500)
Bottom-right: Subtle agricultural photography with ZA-GREEN overlay at 20%
```

**Example copy:**
> **84 Million**
> Hectares of arable land in Sudan — less than 20% productively cultivated.
> Source: FAO, 2025

---

### Template 2: Feature Announcement
**Used for:** Product launches, platform updates
```
Background: White (#FFFFFF)
Left 40%: Feature screenshot / UI mockup (floating, shadow-xl)
Right 60%: 
  - ZA-GREEN-500 overline label (e.g., "NEW FEATURE")
  - type-h2, ZA-NAVY-900 headline
  - type-body-md, ZA-NEUTRAL-700 description
  - btn-primary CTA
Bottom: Logo + tagline
```

---

### Template 3: Quote / Testimonial
**Used for:** Farmer stories, partner quotes
```
Background: ZA-GREEN-900
Full-bleed photo of farmer / partner at 35% opacity
Center: Large quotation mark (ZA-GREEN-400, decorative)
Quote text: type-h3, white, italic, centered
Attribution: type-body-sm, ZA-NEUTRAL-300
Bottom: Logo (white version)
```

---

### Template 4: Agricultural Insight (Arabic-first)
**Used for:** Arabic-primary content for Sudan audience
```
Direction: RTL layout
Background: ZA-SAND-100 (warm, approachable)
Right side: Key figure / icon
Left side: Arabic headline + body text
Color accents: ZA-GREEN-400 for key terms
Logo: Arabic lockup version
```

## 4. HERO BANNERS

### Website Hero — Desktop (1440×800px)
```
Background: Full-bleed aerial photography of Sudanese farmland
Overlay: ZA-NAVY-900 gradient, left 60%, opacity 75%
Content zone (left):
  - Overline: ZA-GREEN-400, 11px, tracking 0.1em, CAPS
  - H1: White, display-lg (56px), weight-700, max 3 lines
  - Subhead: rgba(255,255,255,0.8), body-xl, max 2 lines
  - CTA row: btn-primary (ZA-GREEN) + btn-secondary (white outline)
  - Social proof: 3 trust metrics (farmers, regions, organizations)
Logo: Top-left, white compact version
```

### Investor Hero Banner (1920×1080px — for presentations)
```
Background: ZA-NAVY-900 solid
Z-mark: Giant (800px), right-aligned, opacity 0.06 (watermark)
Left content:
  - ZARATI logo (white)
  - Headline: display-xl (72px), white
  - Subhead: ZA-GREEN-400, body-xl
  - 3 key metrics: Large type, white + label in ZA-NEUTRAL-400
Bottom bar: ZA-GREEN-400 (4px), full width
```
