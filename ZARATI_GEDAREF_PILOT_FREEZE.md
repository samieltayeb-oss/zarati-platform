# ZARATI GEDAREF PILOT FREEZE

## Pilot Objectives

The Gedaref Pilot is designed to test the Zarati platform's technical stability, user experience, and operational viability in a real-world, constrained environment. 

**Anti-Hype Mandate:** The pilot is NOT designed to prove guaranteed economic outcomes (e.g., "increase farmer profits by X%"). It is designed to measure engagement, platform reliability, and data quality.

## Stage 1: Controlled Alpha (Weeks 1-4)
*   **Scale:** 250 - 500 Farmers, 20 - 50 Traders.
*   **Focus:** Core platform stability, authentication success rates, initial listing creation.
*   **Key Metrics:**
    *   Registration success rate (SMS/Email delivery).
    *   Daily Active Users (DAU).
    *   Number of listings created.
    *   System uptime and error rates (monitored via Vercel).
*   **Constraint:** Highly targeted recruitment via trusted local cooperatives. Field activation may PREPARE during R3, but any function relying on market data awaits R4.

## Stage 2: Expansion Beta (Weeks 5-12)
*   **Scale:** 1,000+ Farmers, 100+ Traders.
*   **Focus:** Discovery and interaction metrics, data quality, support burden.
*   **Key Metrics:**
    *   Search queries and filtering usage.
    *   RFQ (Request for Quote) generation rates (if R3 deployed).
    *   Time spent on platform.
    *   Customer support ticket volume and resolution time.
*   **Constraint:** Requires successful mitigation of any critical bugs identified in Stage 1.

## Stage 3: Broad Rollout (Months 3-6)
*   **Scale:** 5,000 Farmers, 250+ Traders.
*   **Focus:** System scalability, network effects, retention.
*   **Key Metrics:**
    *   Month-over-Month (MoM) retention rate.
    *   Organic vs. acquired user ratio.
    *   Platform latency under load.
*   **Constraint:** R3 implementation must be fully stable before initiating this scale.

## Pilot Exclusions
*   No financial transactions will occur on-platform during the pilot.
*   No logistics management will be provided.
*   Zarati assumes zero liability for off-platform agreements made between pilot participants.
