## PART A: INVESTOR DECK IDENTITY

### Visual Language for Investor Materials
The investor deck must communicate three things instantly:
1. This is a serious, enterprise-grade technology company
2. This team understands the market deeply
3. This opportunity is large, defensible, and uniquely positioned

**Aesthetic reference:** Palantir S-1 × Stripe investor materials × African tech unicorn decks (Flutterwave, Andela growth era)

---

### Deck Template — Slide-by-Slide Specifications

#### Slide 1: Cover
```
Background: ZA-NAVY-900 full bleed
Z mark: Large (600px), center-right, 6% opacity watermark
Logo: White, top-left, 200px wide
Headline: type-display-md, white, left-aligned
  "The Digital Operating System for Sudan's Agricultural Economy"
Subline: type-body-xl, rgba(255,255,255,0.7), left-aligned
  "Series [X] | Confidential | [Month Year]"
Bottom-left: Presenter name + title
Bottom bar: ZA-GREEN-400, 4px, full width
```

#### Slide 2: The Problem
```
Background: White
Left 45%: ZA-NEUTRAL-50 bg
  Large pain-point statistic: type-display-md, ZA-NAVY-900
  Short label: type-body-md, ZA-NEUTRAL-600
Right 55%: 3-row problem stack
  Each row: Icon (ZA-NAVY) + type-h4 headline + type-body-sm detail
Section marker: ZA-GREEN-400 left border 4px
```

```
Background: ZA-NAVY-900
3-column layout, centered:
  TAM / SAM / SOM as concentric circles or clean 3-col cards
  Each metric: type-display-md (white) + label (ZA-GREEN-400)
Bottom: Source attribution in type-caption, ZA-NEUTRAL-500

#### Slide 4: The Solution
```

  White bg, shadow-sm, ZA-GREEN-400 icon, type-h4 title

## PART B: GOVERNMENT PRESENTATION IDENTITY

### Design Principles
Government presentations must feel like they belong in a ministry boardroom, not a startup pitch competition. Authority over energy. Clarity over flash.

**Adjustments from investor template:**
- Replace ZA-NAVY-900 dark slides with white/neutral backgrounds
- Reduce large display typography — use h1/h2 scale
- Add official document elements: reference numbers, classification, ministry logo co-placement
- Bilingual slide titles mandatory (Arabic primary, English secondary)
- All charts include data tables
- No gradients, no animations

### Government Deck Slide Specifications

#### Cover Slide
```
White background
Top row: Ministry logo (left) + ZARATI logo (right), balanced
Horizontal rule: 2px ZA-NEUTRAL-300 below logos
Title: Arabic h1 (IBM Plex Arabic, ZA-NAVY-900)
Sub-title: English h2 (Inter, ZA-NEUTRAL-700)
Date / Reference / Classification: type-body-sm, ZA-NEUTRAL-500
Bottom band: ZA-GREEN-400, 6px, full width
```

#### Content Slide — Standard
```
Header: ZA-NEUTRAL-100 bg, 60px height
  Left: Section number + title (Arabic + English)
  Right: ZARATI logo small + reference number
Content area: White bg, side margins 40px
  Font: type-body-lg for all body text
  Lists: Numbered (not bulleted) for formal context
Footer: 1px ZA-NEUTRAL-200 rule
  Left: Document reference
  Center: Ministry name
  Right: Page number
```

#### Data/Impact Slide
```
Header: ZA-NAVY-900 bg, white title text
Metrics: 3-column cards on ZA-NEUTRAL-50 bg
  No shadows — flat, formal
  Large number: type-h1, ZA-NAVY-900
  Label: type-body-sm, ZA-NEUTRAL-600
Below: Data source citations, type-caption
```

## PART C: NGO PARTNERSHIP IDENTITY

### Positioning
NGO materials balance impact storytelling with data credibility. They must appeal to:
- Program directors who need monitoring tools
- Communications teams who need verified impact data
- Grant writers who need narrative + numbers

### NGO Material Adjustments
- More photography — real farmer stories are central
- Warmer color palette — lean into ZA-SAND-400 and ZA-GREEN family
- Impact metrics displayed prominently
- SDG alignment callouts where relevant
- Beneficiary privacy considerations in photo use guidelines
- United Nations / donor logo co-branding guidelines

### NGO Deck Cover
```
Full-bleed photography: Sudan farmland / farmer at work
Left overlay: ZA-GREEN-900 gradient, 65% opacity
Content:
  ZARATI logo: White
  Report type: ZA-GREEN-400 overline
  Title: type-display-md, white
  Partner logo row: White versions of partner organization logos
  Bottom: SDG goal badges if applicable
```
