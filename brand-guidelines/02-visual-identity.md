## 2. LOGO CLEAR SPACE RULES

Clear space = the protected zone around the logo where no other elements may appear.

**Clear space unit = height of capital "Z" in the wordmark (designated as "x")**

```
         ← x →
    ┌────────────────────┐
    │                    │  ↑
    │      LOGO          │  x
    │                    │  ↓
    └────────────────────┘
         ← x →
```

- All four sides: minimum 1× the "x" unit
- On government/formal documents: minimum 1.5× the "x" unit
- Digital (tight layouts): minimum 0.75× the "x" unit — never less

## 4. LOGO CONFIGURATION RULES

### Approved Configurations

| Config | Use Case |
|--------|----------|
| **Full lockup** (mark + bilingual wordmark + tagline) | Hero placements, proposals, presentations, print |
| **Standard lockup** (mark + bilingual wordmark, no tagline) | Headers, footers, co-branding, banners |
| **Compact lockup** (mark + English wordmark only) | Tight digital spaces, small print |
| **Arabic lockup** (mark + Arabic wordmark only) | Arabic-primary documents, government correspondence |
| **Icon only** (Z mark) | App icons, favicons, social media avatars, watermarks |

### Approved Background Treatments
| Version | Background | Logo Treatment |
|---------|------------|----------------|
| **Primary Light** | White (#FFFFFF) | Full color |
| **Primary Dark** | Navy (#0F2D5E) | Full color reversed (white text, leaf remains green) |
| **Agricultural Dark** | Deep Green (#0D3B1E) | Full color (white text, leaf remains green) |
| **Monochrome Dark** | Any dark BG | Single white version |
| **Monochrome Light** | Any light BG | Single navy (#0F2D5E) version |
| **Photographic** | Imagery | White version on dark overlay minimum opacity 40% |

## 5. INCORRECT USAGE — NEVER DO THESE

| # | Violation | Description |
|---|-----------|-------------|
| 1 | **Recolor the mark** | Do not change the Z mark to any non-brand colors |
| 2 | **Stretch or distort** | Do not alter aspect ratio in any direction |
| 3 | **Drop shadows** | No shadows, glows, or visual effects on the logo |
| 4 | **Outline only** | Do not use outline/stroke version of the solid mark |
| 5 | **Crop the mark** | Logo must appear complete — never cropped at edges |
| 6 | **Rotate** | Logo exists only in its approved upright orientation |
| 7 | **Rearrange elements** | Arabic and English wordmarks must stay in approved positions |
| 8 | **Low contrast placement** | Green logo on green backgrounds, navy on dark blue — forbidden |
| 9 | **Add taglines in other languages** | Only approved Arabic and English taglines permitted |
| 10 | **Recreate in different fonts** | Wordmark is a locked asset — never typeset manually |

## 7. COLOR USAGE RULES

### Do:
- Use ZA-NAVY-900 as the dominant background for dark presentations
- Use ZA-GREEN-500 (Leaf) as the primary CTA color on both light and dark
- Use ZA-GOLD-500 exclusively for investor and premium contexts
- Maintain 4.5:1 contrast ratio minimum for all text (WCAG AA)
- Use the Neutral scale for all UI chrome — never use brand colors for borders/dividers

### Do Not:
- Do not use ZA-GOLD on agricultural/farmer-facing materials (feels elitist)
- Do not use more than 3 brand colors in a single layout
- Do not use ZA-GREEN-900 as body text on white (fails contrast at small sizes)
- Do not use gradients between ZA-GREEN-500 and ZA-BLUE-500 (looks generic)
